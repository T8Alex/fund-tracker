# 投资政策书（IPS）

> 最后更新：2026-10-30
> 适用账户：模拟组合（10 万元，非真实资金）

---

## 一、投资目标

| 指标 | 目标 | 容忍范围 |
|---|---|---|
| 年化收益 | 3%–6% | 不承诺，仅参考 |
| 最大回撤容忍 | 10%–15% | 超过 15% 触发全面复核 |
| 持有期 | ≥ 2 年 | 短期波动不干预 |

---

## 二、资产配置区间

| 类别 | 目标占比 | 允许区间 |
|---|---|---|
| 纯债 / 短债 | 50% | 40%–60% |
| 红利 / 固收+ | 15% | 10%–20% |
| 权益（宽基/行业） | 25% | 15%–35% |
| 黄金 / QDII | 5% | 0%–10% |
| 现金 | 5% | 0%–15% |

> 现金比例随再平衡需要浮动；目标权重总和 = 95%，剩余 5% 为现金缓冲。

---

## 三、再平衡规则

- **触发条件**：单只基金实际权重偏离目标权重 ≥ 3 个百分点
- **执行节奏**：分 2–3 次完成，单次不超过目标仓位的 50%
- **资金来源**：优先使用现金；现金不足时先卖超配基金
- **禁止事项**：不因单日涨跌临时调仓；不一次清仓

---

## 四、禁止事项

1. 单票投入 ≤ 总资金的 15%（目标权重控制）
2. 单行业暴露 ≤ 总资金的 25%
3. 不在财报前 5 个交易日建仓
4. 不追涨停、不接飞刀（RSI < 30 且趋势向下时不买入）
5. 不因"评分高"就重仓——评分是排序工具，不是胜率

---

## 五、决策权限与复盘频率

| 事项 | 决策者 | 频率 |
|---|---|---|
| 日常调仓 | 系统建议 + 人工确认 | 每周 |
| 目标权重变更 | 人工确认，记录版本 | 按需 |
| 评分/权重参数调整 | 人工评审后执行 | 每季度 |
| 模型复盘（2/5/20 日） | 自动 + AI 辅助 | 每 2 日 |
| 月度总结 | 自动 | 每月末 |
