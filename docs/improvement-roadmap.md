# 系统改进路线图

日期：2026-10-26

## 范围边界

这套系统继续定位为**本地研究、跟踪、复盘工具**，不做真实资金系统。

明确不做：

- 不接券商/支付宝账户，不读取真实资金
- 不自动下单，不自动调仓
- 不引入交易流水、份额、成本明细
- 不自动修改目标权重或评分规则
- 不接云 API，AI 只用本机模型

因此，组合收益和回撤只能做**持仓快照估算**，不能声称是严格 TWR/XIRR，也不能做交易级归因。报告和界面必须明确标注这一点。

## 分期原则

1. 每期独立可回滚。
2. 先修运行和数据口径，再调投资规则。
3. 不因为某一期完成就自动改目标权重或评分阈值。
4. 每期结束都做一次复盘：是否真的降低了故障率/误判率。
5. 交易流水和真实资金不进入系统，相关结论统一标注为“快照估算”。
6. 纯重构（行为不变的抽取）与行为变更分开提交：先保证抽取后测试原样通过，再改口径。
